# Selected Work seed

`selected-work.ndjson` is generated from the current `content.js` and `cv-content.js` files. It preserves all project text, order, categories, section groups, image descriptions, and original local image paths.

All imported projects start as **Preview only**. After import, upload the files shown in **Imported Cover File** and **Imported Source File**, review both languages, switch **Website Visibility** to **Public on website**, and publish.

Regenerate the file from the repository root with `npm run cms:seed`.
